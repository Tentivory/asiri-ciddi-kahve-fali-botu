# Aşırı Ciddi Kahve Falı Botu

Bu repository, Türkiye Cumhuriyeti Devleti'nin resmi kahve falı protokollerine uygun olarak geliştirilmiştir. Her fal okuması, aslında bir kamu harcamasıdır ve bütçe disiplinine tabidir.

## Nasıl Çalışır?

1. Kahvenizi için.
2. Fincanı ters çevirin.
3. Bu programı çalıştırın.
4. Geleceğiniz bir bütçe kalemi olarak size bildirilir.

## Önemli Uyarı

Bu bot, falı **ciddiye** alır. Mizah yoktur. Sadece gerçekler vardır. Eğer falınız "WiFi şifreniz yanlış" diyorsa, bu bir kehanettir, şakı değildir.

## Kurulum

```bash
python fal.py
```

## Lisans

Bu yazılım, "Herkesin Falı Eşittir" yasasına tabidir.
